# Code of Conduct — RF Sentinel

## Our Commitment

We are committed to creating an open, welcoming, and safe environment for all contributors, regardless of experience, nationality, gender, or technical viewpoint.

## Standards of Behaviour

### Encouraged

- Constructive and specific code review feedback
- Respect for differing viewpoints and experience levels
- Accepting criticism professionally
- Focusing on what is best for the project and its users
- Reporting security vulnerabilities via [SECURITY.md](SECURITY.md) (not publicly)

### Not Acceptable

- Offensive or discriminatory language in any form
- Personal or political attacks
- Public or private harassment
- Sharing another person's private information without consent
- **Using or encouraging the use of this tool for unauthorised transmission, jamming, or surveillance**

## Maintainer Responsibilities

Maintainers have the right to remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct. Maintainers may temporarily or permanently ban contributors who engage in unacceptable behaviour.

## Scope

This Code of Conduct applies across all project spaces: the GitHub repository, issue tracker, pull requests, and any official communication channels.

## Reporting Violations

Report violations to: `conduct@[your-org].com`. All reports will be reviewed and investigated confidentially.
